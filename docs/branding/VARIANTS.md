# Precisão variants

The owner liked "Precisão" (docs/branding/precisao.html) the most. Everything in SPEC.md still applies (both themes, 375px, focus, reduced motion, no em/en dashes, no eyebrows, no section numbers, no gradient text, no glow).

File: docs/branding/precisao-<slug>.html. Bottom section "Por que esta variação": 3 short lines (what changed from Precisão, where it is better, its cost).
